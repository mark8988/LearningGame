# 3D 裝扮資產規範

使用者要求人物及遊戲場景以 3D 呈現，因此 Phase 4 以 3D 部件、錨點與幾何範圍檢查取代原始 PNG 畫布規格。所有場景使用同一份模型，不另外製作戰鬥版或小屋版。

## 資料與座標

- `content-packs/science-g3/items.json`：道具的 `asset` 與 `outfitSlot`。
- `outfit-models.json`：對應 `asset`、`slot`、`style`、十六進位 `color`／`accent`、`anchor: [x,y,z]`。
- `src/components/outfitModel.ts`：程序式幾何工廠，商品單品、試穿與正式穿戴共用。
- `src/components/AvatarRenderer.tsx`：共用人物組裝器；以 Z 正方向為正面、Y 向上、腳底 Y=0。
- `src/data/outfitConfig.ts`：部位順序、固定錨點與允許的幾何尺寸。

| 部位 | 錨點 X,Y,Z | 模型最大尺寸 X,Y,Z |
| --- | --- | --- |
| hair | 0, 1.28, -0.04 | 0.9, 0.7, 0.9 |
| top | 0, 0.61, 0 | 1.2, 1.0, 0.7 |
| bottom | 0, 0.33, 0 | 0.7, 0.5, 0.6 |
| shoes | 0, 0.14, 0.03 | 0.8, 0.5, 0.7 |
| hat | 0, 1.37, 0 | 1.1, 1.0, 1.1 |
| accessory | 0, 0.90, 0.03 | 0.9, 0.8, 0.8 |
| handheld | 0.53, 0.35, 0.13 | 0.6, 0.8, 0.6 |

模型必須有非空且有限的幾何範圍，最低點不得低於腳底，最高點不得超過 Y=2.5。部位與樣式必須匹配；`asset` 不可重複。髮型遇帽子時由組裝器縮短垂直範圍，避免穿出帽頂；上衣衣擺保留褲子的可見空間。

## 新增與驗證

1. 在道具目錄與模型目錄加入一致的 asset／slot；新增樣式時同步擴充 schema、`styleSlots` 及幾何工廠。
2. 保持錨點不變，在部件局部座標建模；材質、幾何建立與釋放由工廠及共用渲染器負責。
3. 執行 `npm run check:assets`，檢查引用、樣式、錨點與實際幾何包圍盒；`npm run build` 內含此檢查。
4. 檢視衣櫃、試穿、小屋、戰鬥及結算；檢查帽子／頭髮、衣擺／褲子與手持物是否互相遮擋。

示範資料重生時，請同步修改 `scripts/generate-demo-pack.mjs`，避免手動新增的模型被生成腳本覆寫。所有外觀資料不得帶入生命、傷害、掉落倍率等戰鬥參數。
