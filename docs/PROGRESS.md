## Phase 2 驗收

- 每關引用 JSON 掉落表，必掉一件、25% 機率額外一件；普通／稀有／史詩權重 70%／25%／5%，史詩為單元限定。
- 同箱與跨次重複裝扮轉換 30 金幣；家具最高九件，滿額掉落同樣轉換 30 金幣，結算清楚列出原因。
- 獎勵一次入庫，開箱不再次發獎，未開箱離開不影響保存。
- 商店家具／服裝／藥水三分頁，提供 3D 單品預覽與購買確認；不足金幣、重複裝扮及滿額庫存不可購買。
- 藥水 25 金幣，回復 50 HP、不超上限、不消耗答題回合；滿血、解析中、勝敗確定及無庫存時不可使用。
- 舊版存檔補入 `potions: 0`，保留金幣、經驗與關卡進度。
- `npm test`：52 項通過，含固定種子一千場掉落模擬，普通比例符合 70% ±3%。
- `npm run test:e2e`：手機與平板橫向觸控模擬共八項通過，覆蓋購買取消／確認、開箱、補血、存檔恢復及不足金幣提示。
- `npm run build`：TypeScript 與正式建置通過。已檢視手機開箱與平板商店截圖。

## Phase 3 驗收

- 12×8 格子吸附，依 JSON 的尺寸及 layer 檢查旋轉後的邊界與同層重疊；桌椅可放在地毯上方。
- 滑鼠及 Pointer Events 觸控拖放、點選後點格子、場景直接移動、家具清單移動／收回；方向鍵選格、Enter／空白鍵擺放、Esc 取消。
- 3D 編輯場景與互動格子共用等角相機投影，視窗改變時更新投影。小屋主畫面與編輯器共用模型、尺寸及 layout。
- 拖放顯示綠／紅框，失敗與取消保留原位置。庫存記錄總持有，家具箱可用量扣除已擺放數；移動、收回不扣庫存或金幣。
- 家具收藏率依不同款式計算，顯示已擺放數與四級稱號，條件詳見 README。
- `npm test`：71 項通過；`npm run test:e2e`：手機及平板共十四項全數通過，含 CDP touch 事件實際觸發 Pointer Events 的拖放與刷新驗證。
- `npm run build` 正式建置通過；人工檢視 3D 佈置、出界紅框及已佈置小屋截圖。
- 六個軟體 WebGL 瀏覽器併行曾造成資源競爭逾時；測試固定兩個 worker 後全綠。編輯器、地圖及商品預覽採按需重繪，避免靜態場景持續占用繪圖資源。

- 新增髮型、褲子、鞋子，十款 3D 模型涵蓋七部位，外觀道具合計十八款。每款有固定錨點與幾何範圍，帽子／髮型及衣擺／褲子遮擋已檢視。

- `npm test`：91 項通過。`npm run test:e2e`：固定兩個 worker，手機及平板共二十項流程通過，包含七部位切換、同部位替換／還原、試穿隔離、購買、刷新恢復及小屋／戰鬥／結算一致。

## CF-A 本機版驗收（2026-10-26）

- 使用者選擇本機版，新增 ASP.NET Core 8 背景 Worker、loopback API 與獨立 React 介面。教材只保存在本機資料目錄；Pages 更新遊戲家長入口，沒有把後端或教材發布成公開服務。
- PDF／EPUB／逐頁 JPG、PNG，檢查副檔名、內容簽章、合計 200 MB、600 頁及 EPUB 展開上限。保留原檔、邏輯頁碼、擷取方法、文字片段與狀態歷程；重啟恢復未完成工作。
- 文字 PDF 使用 PDFPig；掃描頁以 PDFium 轉圖、Tesseract 高精度繁中辨識。避免放大低解析度掃描頁，以版面模式的信心選擇結果，處理相容字形及中文字間空白。
- 封面／目錄或內頁不可讀會停止並要求補頁；正文標題→目錄頁碼→固定三頁低信心切分。科目、年級或單元不明，以及所有 OCR 內容均進家長確認。
- 家長可修改學制、年級、科目、出版社、單元名稱及頁碼；確認採 revision 防止覆蓋過期編輯。原始建議與確認結果分開保存。
- 預設本機規則歸類，不假稱為本機語言模型；保留 Azure OCR 與 Anthropic 介面，HTTP 合約以模擬回應測試，未使用真實雲端金鑰驗收。
- 124 項前端、27 項後端測試通過；10 項手機／平板工廠流程通過，含 EPUB 真實上傳、掃描缺封面補傳、人工確認及不符格式拒絕。遊戲 34 項流程與正式離線回歸保留。
- 十種自製教材各有電子與掃描 PDF，共 20 份學制／年級／科目判讀 20/20 正確；這是受控測試，真實課本的版面與辨識率仍需另驗收。
- 依使用者要求保留 56 個測試素材檔；重跑產生器後 SHA-256 比對確認未刪除、未覆寫。測試原檔、擷取與確認紀錄也保留於 `.local/`。
- 說明與啟動步驟見 [CONTENT-FACTORY.md](CONTENT-FACTORY.md)。CF-A 擷取紀錄尚不是遊戲題庫，自動產題、人工審題及打包仍待 CF-B–CF-C。

## CF-B：混合題型與國中教材（2026-10-26）

- 支援台灣國小至國中 1–9 年級教材產題，補上國文、理化及國中自然科學子科目辨識；提示以家長確認後的年級／科目為準。保留既有高中分類資料，但不開放高中產題。不內建完整國中題庫，課程內容取自上傳教材。
- 從本機 llama.cpp／Ollama 讀取已提供服務的模型，優先 Qwen，可選 Gemma；只允許 loopback，不自動下載或更換模型。背景工作與重啟恢復、取消、部分完成重試皆保存草稿及產生紀錄。
- 每單元 8 題選擇＋4 題填空、3 篇知識草稿，難度 4:6:2，選項分佈只計選擇題。逐題指定考點、型別與輸出結構；重複、出處、選項、答案及格式檢查失敗最多重生三次，不放行不合格草稿。
- 實測發現本機模型會複製前題、漏空格或過長，改為逐題分配考點；填空由模型選原文與答案，程式確認答案只出現一次後挖空。所有結果仍需家長查核，格式檢查不代表學術正確。
- 審核介面支援來源頁／摘錄對照、編輯、核准、附原因退回、單項重生及歷史版本。修改／重生撤銷該項核准，其他核准保留；教材或歸類變更後，舊批次禁止匯出。
- 只有 12 題與至少 2 篇知識核准且檢查通過，才能下載已核准草稿；未核准內容不混入。此為 CF-B 中間產物，正式可遊玩內容包仍待 CF-C。
- 遊戲與 3D 複習接入填空輸入、明列別名、全半形／大小寫／前後空白比對、解析及參考答案。空白不扣血或計次，重複提交不重複獎勵；舊選擇題及存檔相容。
- 130 前端、49 後端測試通過；36 項手機／平板遊戲流程、2 項正式 PWA 斷網流程通過。10 項既有工廠流程及 2 項實際 Qwen 國中混合產題／編輯／退回／重生／已核准匯出／來源失效流程通過。
- 自編國二理化實測曾在約 63 秒產出 12 題與 3 篇待審知識；這是單次本機流程觀察，不代表模型品質或速度基準。測試樣本均非出版課本，仍需真實教材與學科審核。
- 原有 56 檔加植物、國中理化 PDF／文字稿共 60 個素材檔保留；SHA-256 比對確認既有檔案未刪除、未覆寫。說明見 [QUESTION-DRAFTS.md](QUESTION-DRAFTS.md)。

## CF-B 修訂：動態題量與隨機挑戰（0.9.0）

- 依使用者要求，取消新批次固定十二題、8:4 題型及 4:6:2 難度門檻。去重候選知識點，依因果／比較、實驗／程序、公式／計算訊號規劃一至三種考法；題量隨內容而變，知識草稿為一至三篇。
- 產題前顯示候選點、來源頁、複雜度依據及預估題量；規劃隨批次保存，逐題綁定考點及來源頁，不再僅抽幾頁。這是可解釋的規則估算，並非學術難度校準。
- 模型判定考點來源不足時記錄原因並略過，不硬湊。檢查實際產生題目全部核准、無遺漏及出處正確後才能下載；選擇題依實際數量平衡正解位置，各位置相差不超過一題，保留正確答案內容及歷史。
- 舊批次保留原規劃與審核結果，新批次採動態規劃。部分完成續跑保留原題目 ID；長段無標點 OCR、換行及標題與內文同行均有保護及測試。
- 題庫總量與挑戰分開：每場最多隨機十題，通常混入約三成錯題；正常題不足才補其他錯題，忽略跨單元及未知 ID。同場去重、跨場重新隨機，跨場仍可能遇到相同題。
- 取消匯入題庫的十二題限制，至少一題即可。短單元按實際題數挑戰，Boss 生命按比例調整且不超過全對最低傷害總量；十題場沿用原數值。
- 134 前端、61 後端測試通過；36 項手機／平板遊戲、12 項工廠及 2 項正式 PWA 離線流程通過。
- 真實本機 Qwen 對同一份自編國中教材完成兩個單元：基本兩點產出 2 題；含計算、比較與推論的兩點產出 5 題，均保留待審，不再要求十二題。這是受控流程驗證，不代表出版教材命題品質。
- 新增 `adaptive-junior.pdf` 及原文，共 62 個教材素材保留，雜湊比對確認未刪除或覆寫。內容工廠打包成遊戲題庫仍屬 CF-C。

觸控與離線驗證為瀏覽器模擬，尚未實體 iPad 安裝、飛航模式及音效輸出驗收。內容工廠需真實教材確認辨識率及命題品質；內建小三展示包不代表完整課程覆蓋。
