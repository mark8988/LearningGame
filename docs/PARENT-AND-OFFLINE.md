# 家長模式、備份與離線遊玩

## 查看進度

從頁面上方的「家長模式」進入，長按 1.2 秒後回答算術題；鍵盤可按住空白鍵或 Enter。短按、移開、取消觸控或放開按鍵會取消。這是避免誤觸的入口，不是帳號或密碼驗證。離開家長畫面後重新上鎖。

報表顯示目前題庫的累計作答、答對題數、整體正確率、成功冒險、關卡星等與待複習題目。冒險與複習均計入統計；未記錄作答日期或每單元正確率，報表不推算這些資料。

## 備份與換裝置

1. 在家長模式匯出「目前題庫」和「存檔」，保存兩個 JSON。
2. 在另一瀏覽器開啟遊戲，通過家長驗證，加入題庫 JSON，確認後切換至該題庫。
3. 匯入存檔，檢視金幣、作答數與關卡摘要，再確認取代。

題庫檔格式為 `{ "format": "learning-adventure:pack", "version": 1, "files": { ... } }`；`files` 包含 `pack.json`、`questions.json`、`units.json`、`items.json`、`outfit-models.json`、`drops.json`、`encyclopedia.json`、`achievements.json`。不接受可執行程式或外部模型；使用既有程序式 3D 模型定義。格式與引用錯誤會指出檔名及欄位。每單元至少十二題；每檔上限 5 MB，最多十份匯入題庫。

相同 ID、相同內容可再次加入；同 ID 不同內容拒絕覆寫，請由製作者提供新 ID。內容包切換會先保存並重新開啟，各題庫分開記錄進度。內建題庫沿用原有 v1 存檔 key。匯入存檔會檢查版本、內容包 ID、統計、庫存、穿搭、已讀、錯題及家具碰撞；驗證或儲存失敗均保留原進度。重置只影響目前題庫，需輸入「重新開始」再確認。

瀏覽器本機儲存仍可能被清除，不是雲端備份。匯出檔案請自行保管；教材內容須具使用權並經人工審核。CF-A 已提供獨立本機教材上傳、擷取與歸類，可從家長模式開啟；自動產題、審題及題庫打包仍待 CF-B–CF-C，詳見 [CONTENT-FACTORY.md](CONTENT-FACTORY.md)。

## 安裝與離線

先在線上開啟正式網站，等到「離線遊玩已就緒」，再斷網。3D 場景、角色模型、內建題庫、圖示與程式都預先快取；匯入題庫存在同一瀏覽器，也可離線切換。可使用瀏覽器的安裝功能，或 iPad Safari「分享 → 加入主畫面」。需 HTTPS 或本機 localhost；開發伺服器不啟用快取，請以 `npm run build`、`npm run preview` 驗證。

Service Worker 在安裝時完整快取新版本。偵測到更新會顯示「保存並更新版本」；確認後才啟用並重新開啟，避免答題中自動刷新。快取以網站 scope 隔離，只清理本遊戲的舊版本。若未就緒，請保留網路並重新整理；清除網站資料後須重新準備。

```sh
npm test
npm run build
npm run test:e2e
npm run test:offline
```

`test:offline` 對正式建置執行手機／平板測試：準備快取、停網、重開、通關、購買家具、擺放、再次重開確認進度。設定 `LEARNING_TEST_URL` 可驗證已部署的子目錄網站，測試使用隔離瀏覽器資料，不影響使用者存檔。

## 閱讀與音效

「閱讀與音效」提供放大字體、注音及音效開關。音效預設關閉，使用本機 Web Audio 產生答題與獎勵提示；無需下載音檔。注音預設開啟，題目可選填 `zhuyin`：以空白分隔每個漢字的注音，不包含標點，例如 `冰塊` 對應 `ㄅㄧㄥ ㄎㄨㄞˋ`。以 `<ruby>` 呈現，不自動猜讀音；內建包目前五題提供注音，其餘題目保留原文。

目前測試使用 Edge 的手機／平板模擬；實體 iPad 安裝、音效輸出及飛航模式仍待裝置驗收。
